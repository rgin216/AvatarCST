# Synthetic audio starter inputs

Select these WAV files together in the browser deployment-latency panel. They mirror `../deployed-latency-inputs.json`, in filename order:

1. `01-name.wav`: “My name is Alex.”
2. `02-gardening.wav`: “I enjoy gardening.”
3. `03-unsure.wav`: “I am not sure.”

Generated locally with Windows System.Speech, Microsoft David Desktop, rate 0 and volume 100. These contain synthetic speech only. File format, durations and SHA-256 checksums are recorded in `manifest.json`. Regenerate from `backend` using `powershell.exe -File scripts/generate-latency-audio.ps1`; regenerated bytes may differ with the installed voice/version, so update checksums before research use.

These are connectivity fixtures, not an adaptive simulated participant or a full session protocol. The runner sends the next selected file after narration ends. It does not inspect a follow-up question, choose a relevant answer or insert an “I don't know” fallback. After three inputs it stops. Prepare a longer script-specific sequence or answer manually when testing branching conversations. Avoid interpreting an unrelated queued answer as a realistic response to a follow-up question.
