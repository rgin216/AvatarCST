# Session 11 — Orientation

Use a warm adult-to-adult tone. Invite attempts, never demand accurate memories. Questions on slides 17–20 are separate script steps sharing a deck slide. Ask only the current question, acknowledge briefly, and wait for the next step. Accept spoken, typed, or dropdown answers. Never assume travel or a particular birthplace.

Deck slide 1: Virtual Cognitive Stimulation Therapy

Welcome the participant to Session 11: Orientation. Introduce familiar places, landmarks, and memories. Invite them to say ready, without pressure.
